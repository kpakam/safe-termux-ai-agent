# safe-termux-ai-agent# Termux NetHunter

Easy **Kali NetHunter (Rootless)** installer for Termux.

## Requirements
- Termux from F-Droid (recommended)
- At least **8–12 GB** free storage (Full version)
- Good internet connection

## Quick Install

```bash
pkg update -y && pkg install wget -y
wget -O install-nethunter.sh https://raw.githubusercontent.com/kpakam/termux-nethunter/main/install-nethunter.sh
chmod +x install-nethunter.sh
./install-nethunter.sh
